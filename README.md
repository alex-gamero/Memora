# Memora

**Learn languages with flashcards.**
Flip, browse and build your own decks in **Spanish** and **Anishnabek**, from basic words to full conversations.

## Features
| | |
|---|---|
| 🃏 **Flip cards** | See the word, flip the card for the translation, with slide animations between cards |
| 🌎 **Two languages** | Spanish and Anishnabek decks |
| 📈 **Three levels** | Basic (single words), Intermediate (everyday questions) and Advanced (full conversations) |
| ✏️ **Make it yours** | Add new cards, edit the current one or delete it |
| 🔍 **Find a deck fast** | Search decks by name and filter them by language |

---

## How it works
1. Pick a deck on the home page, or search for one.
2. Press **Start Studying**.
3. Use **Flip** to see the translation and the arrows to move between cards.
4. Add, edit or delete cards as you go.

## 🛠️ Tech Stack
- **HTML5**
- **CSS3** (3D card flip and slide animations)
- **Vanilla JavaScript**

### Project structure
```
Memora/
├── index.html            # Home page with deck search & filter
├── spanishDeck.html      # Spanish study view
├── anishnabekDeck.html   # Anishnabek study view
├── loginPage.html        # Login (in progress)
├── registration.html     # Sign up (in progress)
├── buttons.js            # Decks, flashcard logic, search
└── style.css
```

### Run locally
```bash
git clone https://github.com/alex-gamero/Memora.git
cd Memora
# open index.html in your browser
```
